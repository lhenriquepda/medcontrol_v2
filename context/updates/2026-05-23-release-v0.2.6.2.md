# Release v0.2.6.2 — 2026-05-23 (vc 87 mandatory)

> **Hotfix crítico** sobre v0.2.6.1 vc 85 reportado pelo user em prod.
> Mandatory pra forçar update modal — bugs vc 85 corrompiam UX categoria.

## Resumo executivo

3 bugs P0 detectados pelo user em prod ("antibióticos pros filhos não aparecem
categorizados", "Analytics só mostra Outros", "cadastro de tratamento mobile
é uma zona — campo some, teclado por cima, sugestões somem ao scroll").

Diagnóstico revelou que o BD estava correto (47 doses antibiótico done com
`group_id='antibiotico'`), mas DOIS pontos do data fetch omitiam a coluna:

1. `DOSE_COLS_LIST` em `src/services/dosesService.js` (SELECT PostgREST)
2. RPC `get_dashboard_payload` `jsonb_build_object`

Ambos receberam fix. Plus rewrite completo de `MedNameInput.jsx` mobile-first
(BottomSheet fullscreen — anti-pattern Roteiro P9.8) + expansão catálogo
+88 brand-names BR cobrindo 6 personas (Roteiro P9.4).

## Bugs fixed

| # | Sintoma reportado | Root cause | Fix |
|---|---|---|---|
| #0012 | Histórico/Analytics só mostra "Outro" | `DOSE_COLS_LIST` PostgREST SELECT omitia `group_id, cmed_class` → fallback `d.group_id || 'outro'` agrupava tudo | Adicionado ao SELECT (commit `2bf8dad`). Migration RPC `get_dashboard_payload` incluiu campos no `jsonb_build_object` |
| #0013 | TreatmentForm crasha "Cannot access 'Se' before initialization" | `useClassifyMedication(form?.medName)` referenciava `form` ANTES de `const [form, setForm] = useState()`. Bug TDZ pré-existente v0.2.5.0 só explodia em build minificado | Reorder useState ANTES de useClassifyMedication (commit `23213f9`) |
| #0014 | Mobile picker UX terrível — campo some, teclado por cima, sugestões somem ao scroll | Dropdown inline em Capacitor WebView Android: teclado virtual reposiciona, scroll body desfocava input, click-outside captura tap em scrollbar interno | `MedNameInput.jsx` reescrito mobile-first: `matchMedia('(max-width:768px)')` OR coarse pointer → trigger button abre FULL-SCREEN sheet `position:fixed inset:0 z-index:1500`. Header fixo + lista flex-1 `overscroll-behavior:contain`. Lock body scroll, autoFocus delay 80ms, fontSize:16 anti-zoom Android. Desktop mantém dropdown inline (commit `2bf8dad`) |
