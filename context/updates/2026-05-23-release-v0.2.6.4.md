### P3.2 — audit_log LGPD append-only

**Migration:** `20260523133224_v0_2_6_4_audit_log_p3_2.sql`

- Table `medcontrol.audit_log` (id BIGSERIAL, user_id, patient_id, action TEXT CHECK 19 actions, metadata JSONB, createdAt)
- 19 actions cobertas: dose_marked_done/skipped, dose_undone, sos_registered/forced_override, patient_shared/unshared, share_access_changed/extended/expired, treatment_created/paused/resumed/ended/alert_level_changed, account_deleted, data_exported, feature_flag_changed, re_categorize_null_rows_cron, cmed_sync_run
- RLS: SELECT owner_or_admin (user_id=auth.uid() OR has_patient_access(patient_id) OR is_admin). INSERT/UPDATE/DELETE só via RPC SECURITY DEFINER
- Helper `write_audit_log(action, patient_id?, metadata?)` — falha silenciosa pra nunca quebrar operação principal
- `confirm_dose_v2`, `skip_dose_v2`, `undo_dose_v2` atualizadas pra escrever audit
- `cleanup_audit_log()` retention policy: dose_*/sos_* 2y, treatment_* 2y, share_* 1y após patient NULL, feature_flag_* 6M, cron_* 90d, account_deleted/data_exported indefinido (LGPD obrigação)
- Cron mensal `cleanup-audit-log-monthly` (0 5 1 * *)
