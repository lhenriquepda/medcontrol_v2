## Bug #0032 (P1) — FIXED

**Sintoma:** Sentry capturou repetidos `400 Bad Request` para `/rest/v1/patient_shares?...or=(expiresAt.is.null,expiresAt.gt.2026-05-26T03:39:35.384Z)` no boot. Apenas após boot/idle longo (staleTime 5min cobre demais nav). Resultado: `outboundSharedCount=0` → `hasCollabContext=false` → useRealtime gate fecha → **Realtime desliga errado** pra user que tem APENAS shares enviados (sem recebidos).

**Root cause:** PostgREST parser de `.or()` usa `.` como separador entre `coluna.operador.valor`. Quando o valor contém `:` (timestamps ISO 8601 sempre têm `T03:39:35.384Z`), o parser interpreta `gt.2026-05-26T03` como coluna+op+valor → restante (`:39:35.384Z`) é junk → 400.

**Fix:** envolver valor com aspas duplas (PostgREST aceita quoted values com chars especiais):

```js
// ANTES (400):
.or(`expiresAt.is.null,expiresAt.gt.${nowIso}`)

// DEPOIS:
.or(`expiresAt.is.null,expiresAt.gt."${nowIso}"`)
```

**Arquivo:** `src/hooks/useAccessiblePatientIds.js:76`

## Bug #0033 (P2) — FIXED

**Sintoma:** Console mostrava 5× `401 Unauthorized` no boot do app pós-idle longo. Endpoints atingidos: `/rest/v1/patients?select=...createdAt,updatedAt`, `/rest/v1/treatments?...&offset=0&limit=1000`, etc.

**Root cause:** Race condition cold-start:
1. App boot → cache Zustand hidrata UI instantâneo (v0.2.8.4 M1)
2. React mount → `useQuery` dispara (usePatients/useTreatments/useAccessiblePatientIds)
3. Queries usam JWT antigo lido do SecureStorage → bate Supabase → **401**
4. supabase-js detecta token expirado → dispara `refreshSession()` em background
5. ~500ms-2s depois, refresh completa → próximas requests OK
6. Mas as primeiras (do mount) já falharam → noise console + Sentry events

**Fix:** `await getValidSession()` em `main.jsx` `boot()` ANTES de `ReactDOM.createRoot()`. `getValidSession()` (sessionManager v0.2.7.0) lê session local + refresh proativo se expira em <30s. Timeout interno 8s. Fail soft: sem sessão → mount segue → login screen renderiza.

**Arquivo:** `src/main.jsx` (entre Capacitor Network.getStatus e RealtimeManager init)

**Custo:** cold-start +200-500ms quando token precisa refresh. Aceitável vs noise console + Sentry quota.
