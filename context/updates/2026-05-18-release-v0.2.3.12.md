## Decisões arquiteturais

### NB-4 100% — flushPersistImmediate vs alternatives

Considerado:
- **A. Throttle 1s** (implementado): janela ~250-300ms — 4× melhor
- **B. localStorage shadow log** sync write antes mutation: 100% safe mas duplica TanStack persist queue
- **C. Abandonar throttle**: write IDB cada cache update — perf hit ~5-10×

Escolhido A. B aceitável se device físico mostrar threshold ainda >100ms na prática.
Doc `mutationRegistry.js:55-59` corrigir threshold real (TODO v0.2.3.13).

### Regra 17 Appium mandatory

QA sessão 1 (CDP eval) falhou silenciosamente em 6 bugs. CDP `.click()` ≠ touch real.
Adicionado RULES.md Regra 17 + WORKFLOW §11b "Appium SEMPRE" + recipe
emulator-setup.md §5 reescrita com Appium W3C como primário, uiautomator dump como
fallback "leitura apenas".
