### Feature #299 — Tabela autoritativa `app_releases` para in-app update banner

- Substitui mapa hardcoded `VERSION_CODE_TO_NAME` (parava em vc 70) + cadeia frágil Vercel `/version.json` (dessincronia com Play AAB shipping)
- Tabela `medcontrol.app_releases` com `version_code PK + version_name + is_mandatory BOOLEAN + whatsnew TEXT + shipped_at`
- RLS public read-only (`FOR SELECT USING (true)`), sem RPC wrapper
- Cache localStorage `dosy_vname_{vcode}` evita re-fetch (releases imutáveis)
- IA atualiza no Passo 12 via INSERT idempotente (ON CONFLICT DO NOTHING)
- `is_mandatory=true` força modal vermelho full-screen bloqueante sem dismiss. Default `false` = banner verde dismissable
- README Passo 12.1 expandido com 3 decisões IA (mandatory + whatsnew + confirm user)
- `UpdateBanner.jsx` ganhou variante modal com header gradient red, ícone warning, bloco "Novidades" condicional + footnote
- `useAppUpdate.js`: chain simplificada (Play Core availableVersion → DB autoritativa → fallback "versão N")
